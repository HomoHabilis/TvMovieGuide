TvMovieGuide uses the free TMDB database for trending data, streaming availability, and ratings — with direct links to Rotten Tomatoes and IMDb for every title. To get started, you need a free TMDB API key.

1

Create a free account at themoviedb.org/signup

2

Go to Settings → API and request an API key (choose the Developer option — it's instant and free).

3

Copy your API Key (v3 auth) and paste it below.

Your key is saved only in your browser (localStorage) and is never transmitted to any third-party server.
